# ПФОР | B2B AI Consulting

Мультиагентная система автоматизированной генерации бизнес-стратегий на базе Google Gemini API.

## 🚀 Возможности

- **Точный дизайн** по предоставленному макету (хедер, бейджи, 2-колоночный блок агентов, поле ввода бизнес-задачи, футер).
- **Прямая интеграция с Google Gemini API**:
  - Поддержка моделей `gemini-2.5-flash` и `gemini-1.5-flash`.
  - Возможность указать API-ключ через интерфейс (сохраняется в `localStorage`) или через переменную окружения `VITE_GEMINI_API_KEY`.
  - Автоматический умный режим симуляции/демо, если ключ ещё не указан.
- **Мультиагентная логика**:
  - 🎯 **Director** — стратегический анализ, корневые проблемы и вектор решения.
  - 📈 **Marketer** — GTM, ICP, каналы привлечения и конверсия воронки.
  - 💡 **Financier** — юнит-экономика (CAC, LTV, Payback), тарифная сетка и финансовый план.
  - 📋 **Editor** — сведение выводов в пошаговый action plan (1-14 дней, 15-45 дней, 46-90 дней).
- **Дополнительно**:
  - Переключение тем: Светлая / Тёмная (с сохранением состояния).
  - Переключение языка интерфейса: RU / EN.
  - Копирование и экспорт сгенерированной стратегии в `.md`.
  - Адаптивная верстка (Mobile / Tablet / Desktop).

## 🛠 Запуск проекта

1. Установка зависимостей:
   ```bash
   npm install
   ```

2. Запуск в режиме разработки:
   ```bash
   npm run dev
   ```
   Сайт будет доступен по адресу: `http://localhost:5173`

3. Сборка для продакшена:
   ```bash
   npm run build
   ```

## 🔑 Настройка Gemini API ключа

Получите бесплатный ключ в [Google AI Studio](https://aistudio.google.com/app/apikey), затем:
- Либо нажмите на бейдж **"Gemini Demo Mode" / "API Docs"** в правом верхнем углу сайта и вставьте ключ.
- Либо создайте файл `.env` в корневой папке:
  ```env
  VITE_GEMINI_API_KEY=AIzaSy...
  ```
